# Screenshots

The images in this folder are the ones the main [README](../README.md) points at. Three are expected:

| File | Shows |
| :--- | :--- |
| `screenshot-dusk.png` | The reader in the **Dusk** theme — also used as the hero image |
| `screenshot-moss.png` | The reader in the **Moss** theme |
| `screenshot-parchment.png` | The reader in the **Parchment** theme |

## How to take them

Open a PDF you're happy to show — a paper with a figure or a chart in it makes the smart invert obvious — and capture the browser viewport, not the whole desktop.

- **Format:** PNG
- **Width:** about 1600px (a HiDPI screenshot of an 800px-wide window is ideal, and stays crisp on retina displays)
- **Framing:** include the toolbar at the bottom, and scroll so a page of body text plus a figure is visible
- **Consistency:** use the same document, the same page, the same zoom and the same window size for all three, so the table reads as a true comparison

Drop the files in here with exactly those names and the README picks them up.
